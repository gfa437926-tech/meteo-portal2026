التشغيل المحلي الفوري باستخدام Docker Compose (الخيار الأسهل)

قم بفك ضغط ملف الـ ZIP، وافتح موجه الأوامر (Terminal) في مجلد المشروع ونفّذ الأمر التالي:

أمر التشغيل السريع: انسخ والصق في التيرمينال
docker compose up -d
📌 بعد تشغيل الأمر، افتح الروابط التالية في المتصفح:
  • البوابة العامة للمواطنين: http://localhost:8080
  • لوحة تحكم المشرف (CMS): http://localhost:8080/admin
  • دليل التشغيل والشرح: http://localhost:8080/guide.html
  • واجهة فحص الـ API: http://localhost:8080/api/agency

أو التشغيل المباشر بدون Docker (Native Run):

# تثبيت المكتبات وتشغيل Python FastAPI pip install -r requirements.txt python main.py
2

النشر السحابي السيادي بضغطة زر واحدة (1-Click Cloud Deploy)

يمكنك إتاحة الموقع على الإنترنت لجميع المواطنين مجاناً أو على نطاق رسمي:

🚀 النشر عبر Render.com render.yaml
  1. ارفع هذا المجلد إلى حسابك في GitHub أو GitLab.
  2. سجّل الدخول إلى Render.com واضغط New Blueprint.
  3. اختر المستودع وسيقوم Render تلقائياً باكتشاف render.yaml وبناء الموقع بدوكر وتوفير HTTPS مجاني!
🚂 النشر عبر Railway.app railway.json
  1. سجّل الدخول في Railway.app واضغط New Project.
  2. اختر Deploy from GitHub repo واختر مجلد المشروع.
  3. سيتعرف Railway على الـ Dockerfile ويتم النشر تلقائياً خلال 60 ثانية.
3

تشغيل تطبيق فلاتر للهواتف الذكية (iOS & Android)

المشروع يحتوي على تطبيق دارت وفلاتر كامل داخل مجلد /flutter_app:

# الانتقال لمجلد تطبيق الجوال

cd flutter_app

# تحميل حزم ومكتبات فلاتر

flutter pub get

# تشغيل التطبيق على المحاكي أو الهاتف المتصل

flutter run
